# AGENTS.md Updater Skill

작업 중 발생한 결정사항을 `AGENTS.md`에 "재사용 가능한 규칙"으로 반영합니다.

## 언제 쓰는가

- 사용자가 "이번 작업 내용 기반으로 AGENTS.md 갱신"을 요청할 때
- 반복적으로 같은 실수가 발생해 룰로 고정할 필요가 있을 때
- 도구 버전/배포 절차/금지 명령 같은 운영 가드레일을 문서화할 때

## 입력 소스

다음 우선순위로 근거를 수집합니다.

1. `git diff` / `git status` (이번 작업에서 실제 변경된 내용)
2. 직전 작업에서 확인된 오류 메시지(예: 버전 불일치, PATH 문제)
3. 기존 `AGENTS.md`의 중복/충돌 규칙

## 추출 규칙 (중요)

`AGENTS.md`에는 아래만 반영합니다.

- 반복 가능하고 일반화 가능한 규칙
- 실패 재발 방지에 직접 도움이 되는 규칙
- 레포 구조/운영 방식에 종속된 절차

반영하지 않습니다.

- 일회성 상황 설명
- 개인 환경의 임시 우회법
- 민감정보, 내부 토큰/키, 계정 식별자

## 업데이트 절차

1. `AGENTS.md`를 읽고 기존 섹션 구조를 파악한다.
2. 이번 작업의 후보 규칙을 3~7개로 요약한다.
3. 각 후보를 `지속성/재현성/보안성` 기준으로 필터링한다.
4. 기존 규칙과 충돌 없도록 문장을 합치거나 대체한다.
5. `apply_patch`로 `AGENTS.md`만 수정한다.
6. 최종 보고 시 아래 3가지를 반드시 제공한다.
- 추가/수정된 규칙 목록
- 왜 룰로 승격했는지 한 줄 근거
- 제외한 후보(있다면)와 제외 이유

## 문장 스타일

- 짧고 명령형으로 작성한다.
- "해야 한다/하지 않는다" 형태를 사용한다.
- 툴/경로/버전은 백틱으로 표기한다.

## 권장 섹션

- `핵심 원칙`
- `도구/버전 정책`
- `배포/검증 절차`
- `금지 작업`

기존 섹션이 있으면 재사용하고, 없으면 최소 섹션만 추가합니다.

## 빠른 실행 명령

```bash
git status --short
git diff -- AGENTS.md
```

필요 시:

```bash
rg -n "terramate|pre-commit|argocd|external-secret" .
```

## 이 스킬이 특히 잘 맞는 예시

- "이번 트러블슈팅 내용 AGENTS.md에 자동 반영해줘"
- "다음부터 같은 실수 안 나게 규칙으로 남겨줘"
- "지금 변경사항 보고 운영 가드레일 업데이트해줘"
