# Daily Work Log Skill

오늘 작업한 내용을 수집하여 `docs/logs/daily/YYYY-MM-DD.md`에 정리합니다.

## 저장 위치

```
docs/logs/daily/YYYY-MM-DD.md
```

## Workflow

### 1. 데이터 수집

```bash
# 오늘 커밋 로그 + 변경 파일
git log --since="$(date +%Y-%m-%d)T00:00:00" --until="now" \
  --pretty=format:"%h %s" --date=short --all --name-only

# 커밋 메시지가 부실하면 변경 파일 상세 확인
git show {commit_hash} --stat
```

추가로 **현재 대화 컨텍스트**에서 작업한 내용도 수집:
- 직접 실행한 명령어 결과 (terraform apply, kubectl 등)
- 트러블슈팅 과정
- 의사결정 사항

### 2. 기존 파일 확인

```bash
# 오늘 날짜 파일이 이미 있는지 확인
cat docs/logs/daily/$(date +%Y-%m-%d).md 2>/dev/null
```

- **파일 없음** → 새로 생성
- **파일 있음** → 기존 내용 읽고, 새 작업 추가 후 전체 리팩토링

### 3. 내용 분류 및 정리

커밋 + 대화 컨텍스트를 분석하여:
- 카테고리별 그룹화 (작업 내용에 맞게 자유롭게)
- 같은 작업의 여러 커밋은 하나로 통합
- 중요도 순 정렬

### 4. 파일 작성

**기존 파일이 있는 경우**:
1. 기존 내용 읽기
2. 새 작업 내용 병합 (중복 제거)
3. 전체 내용을 리팩토링하여 재정리
4. 파일 덮어쓰기

**새 파일인 경우**:
1. 템플릿에 맞춰 작성
2. 파일 생성

## 템플릿

```markdown
# Daily Log - YYYY-MM-DD

## 작업 내용

### {카테고리 1}
- 작업 항목 설명
  - 세부 사항이 있으면 서브 항목
  - 결과/상태 (성공, 실패, 진행중 등)

### {카테고리 2}
- 작업 항목 설명

## 관련 커밋
- `hash` message
- `hash` message

## 메모
- 삽질한 내용, 다음에 참고할 사항
- 의사결정 배경 (git에서 안 보이는 맥락)
```

## 카테고리 예시

고정 카테고리 없음. 작업 내용에 맞게 자유롭게:
- CI/CD 파이프라인
- 인프라 (Terraform/Terramate)
- K8s 매니페스트
- 모니터링/운영
- 설정/문서화
- 트러블슈팅

## 작성 규칙

- 한국어로 작성
- 구체적으로 기술 (무엇을 왜 했는지)
- 할루시네이션 금지: 커밋/대화에 없는 내용 작성 금지
- "메모" 섹션에는 git diff에서 안 보이는 맥락 기록 (왜 이렇게 했는지, 삽질 내용 등)

## 리팩토링 규칙 (기존 파일 업데이트 시)

기존 내용 + 새 내용을 합친 후:
1. 카테고리 재분류 (비슷한 작업끼리 묶기)
2. 중복 항목 제거
3. 시간순 → 카테고리순으로 재정렬
4. 커밋 목록 병합 (중복 제거)
5. 메모 섹션도 병합

## Example Usage

**사용자**: `/daily-log` 또는 "오늘 작업 정리해줘"

**Codex**:
1. `git log --since=today` 로 커밋 수집
2. 대화 컨텍스트에서 추가 작업 내용 수집
3. `docs/logs/daily/2026-02-02.md` 존재 여부 확인
4. 파일 생성 또는 업데이트
5. 결과 요약 출력
